# カスタムエンチャント一覧

このページでは有効なカスタムエンチャントの効果一覧を紹介します。

有効なカスタムエンチャント一覧（NPC、またはエンチャ台、交易、宝箱から入手可能）
  • 出血（Bleed）：敵に出血スタックを付与し、移動速度を低下させます。レベル：I～VI
  • 串刺し（Impale）：大ダメージ＋鈍足V。レベル：I～IV
  • 保護（Protection）：近くの味方を自動回復＋状態異常治癒。レベル：I～V
  • 激流（Torrent）：水中でダメージ増加。レベル：I～IV
  • 審判（Judgement）：毒ダメージ＋再生効果。レベル：I～V
  • サプライズ（Surprise）：背後にテレポート。レベル：I～IV
  • スタン（Stun）：遅延＋弱体化＋自身の鈍足解除。レベル：I～III
  • 不浄（Unholy）：ウィークネス＋ウィザー効果。レベル：I～V
  • 矢筒（Quiver）：攻撃者を空中に吹き飛ばす。レベル：I～VI
  • ファット（Fat）：ダメージ軽減＋吸収効果。レベル：I～VI
  • 呪い（Hex）：ダメージ減少＋反射。レベル：I～IV
  • 蛮族（Barbarian）：斧ダメージ増加。レベル：I～IV
  • 明瞭（Clarity）：盲目効果解除。レベル：I～III
  • 死の使者（Deathbringer）：2倍ダメージ。レベル：I～III
  • 二連撃（Doublestrike）：2回攻撃。レベル：I～III
  • 酩酊（Drunk）：鈍足＋攻撃速度低下＋ストレングス。レベル：I～IV
  • 啓発（Enlighted）：ダメージ時にハート回復。レベル：I～III
  • ギア（Gears）：装備時に移動速度上昇。レベル：I～III
  • 探究者（Inquisitive）：経験値ドロップ増加。レベル：I～IV
  • 反転（Inversion）：ダメージ無効化＋HP回復。レベル：I～IV
  • ライフスティール（Lifesteal）：攻撃時に体力奪取。レベル：I～V
  • オーバーロード（Overload）：最大体力増加。レベル：I～III
  • 激怒（Rage）：コンボ攻撃で追加ダメージ。レベル：I～VI
  • 沈黙（Silence）：敵のカスタム防具エンチャント発動阻止。レベル：I～IV
  • 装甲（Armored）：ソードダメージ軽減。レベル：I～IV
  • 駆除者（Exterminator）：Undead Ruse等の能力無効化。レベル：I～III
  • 鍛冶屋（Blacksmith）：防具耐久値回復＋ダメージ半減。レベル：I～V
  • 貪食（Devour）：出血スタック時ダメージ増加。レベル：I～IV
  • 減少（Diminish）：次ダメージ半減。レベル：I～VI
  • 武装解除（Disarmor）：敵の防具を外す。レベル：I～VIII
  • 死神（Deathgod）：HP低下時に回復。レベル：I～III
  • 反重力（Antigravity）：スーパージャンプ。レベル：I～VIII
  • スナイパー（Sniper）：ヘッドショットでダメージ増加。レベル：I～V
  • 破壊（Destruction）：周囲の敵にダメージ＋デバフ。レベル：I～V
  • 極限狂気（ExtremeInsanity）：ソード持ちに追加ダメージ。レベル：I～VIII
  • メガヘビー（MegaHeavy）：弓ダメージ軽減。レベル：I～V
  • 呪われた呪い（BewitchedHex）：ダメージ減少＋追加ダメージ。レベル：I～IV
  • 強力なクリーブ（MightyCleave）：範囲ダメージ。レベル：I～V
  • 強力なサボテン（MightyCactus）：攻撃阻止＋反射。レベル：I～II
  • 誘導ロケット脱出（GuidedRocketEscape）：低HP時に飛行。レベル：I～III
  • 魂の硬化（SoulHardened）：ソウルトラップ防止＋耐久値減少抑制。レベル：I～III
  • 多形的形而上（PolymorphicMetaphysical）：鈍足解除。レベル：I～IV
  • 強化タンク（ReinforcedTank）：斧ダメージ軽減。レベル：I～IV
  • 疫病運び（EpidemicCarrier）：瀕死時にクリーパー召喚＋デバフ。レベル：I～VIII
  • 神のオーバーロード（GodlyOverload）：最大体力大幅増加。レベル：I～III
  • 反射ブロック（ReflectiveBlock）：ダメージ軽減＋反射。レベル：I～III
  • 熟練探究者（MasterInquisitive）：経験値大幅増加。レベル：I～IV
  • 惑星死の使者（PlanetaryDeathbringer）：1.5倍ダメージ。レベル：I～III
  • 神聖啓発（DivineEnlighted）：大量HP回復。レベル：I～III
  • 致命的スナイパー（LethalSniper）：ヘッドショット倍率最大4.5倍。レベル：I～V
  • 原子爆破（AtomicDetonate）：最大7x7爆発。レベル：I～IX
  • タイタントラップ（TitanTrap）：強化鈍足。レベル：I～III
  • 双方向テレポート（BidirectionalTeleportation）：敵を引き寄せ。レベル：I～IV
  • 熟練鍛冶屋（MasterBlacksmith）：防具耐久値回復＋ダメージ減少。レベル：I～V
  • 復讐の減少（VengefulDiminish）：ダメージ半減＋反射。レベル：I～VI
  • エイリアンインプラント（AlienImplants）：HP2倍回復＋空腹減少無効。レベル：I～III
  • エーテル回避（EtherealDodge）：高発動率＋SpeedV。レベル：I
  • 聖騎士装甲（PaladinArmored）：ソードダメージ軽減＋Blessed効果。レベル：I～IV
  • 悪魔的ライフスティール（DemonicLifesteal）：HP大幅回復。レベル：I～V
  • 深い出血（DeepBleed）：強力な鈍足＋追加ダメージ。レベル：I～VI
  • シャドーアサシン（ShadowAssassin）：距離でダメージ変化。レベル：I～V
  • ローグ（Rogue）：最大2倍ダメージ（ソウル消費）。レベル：I～III
  • 妨害（Sabotage）：ロケットエスケープ阻止（ソウル消費）。レベル：I～V
  • 自然の怒り（NaturesWrath）：広範囲凍結＋大ダメージ（ソウル消費）。レベル：I～IV
  • フェニックス（Phoenix）：死亡時HP全回復（ソウル消費）。レベル：I～III
  • テレブロック（Teleblock）：エンダーパール封印（ソウル消費）。レベル：I～V
  • 魂の罠（SoulTrap）：ソウルエンチャント無効化（ソウル消費）。レベル：I～III
  • 不死（Immortal）：防具耐久値減少防止（ソウル消費）。レベル：I～IV
  • 神聖焼却（DivineImmolation）：範囲魔法＋炎（ソウル消費）。レベル：I～IV
  • 逆説（Paradox）：ダメージ分配回復（ソウル消費）。レベル：I～V
  • 魂の粉砕（SoulGrind）：討伐時にソウル獲得。レベル：I～III
  • 無効化（Neutralize）：防御系エンチャント無効化。レベル：I～V
  • ハロウィン化（Halloweenify）：ヘルメットをカボチャ化。レベル：I～V
  • 獣の刻印（MarkOfTheBeast）：ダメージ2倍（最大5秒）。レベル：I～VI
  • 恐怖（Horrify）：広範囲に恐怖効果。レベル：I～IV
  • 連鎖ライフスティール（ChainLifesteal）：周囲から体力吸収。レベル：I～II
  • 魂の吸引（SoulSiphone）：ソウル＋耐久値吸収。レベル：I～IV
