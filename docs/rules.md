# サーバールール・規約

下記のルールは参加する上で必ずお守りください。

- 荒らし行為は禁止
- チート・バグ利用の禁止
- 他プレイヤーへの迷惑行為禁止
- 暴言、喧嘩等が無いようにお願いします。
- マナーやモラルに欠ける行為
- 出会い厨や嫌がる方へのセクハラ、下ネタ行為 (互いの同意があればセーフ)
- 他のサーバーへの勧誘、引き抜き行為
- チート等、ゲーム内における不正行為
- 必要以上の指導、指摘、指示厨
- 自分本位、自己中、協調性が無い方
- ディスコードは必須です。不参加が発覚した場合はBAN対象になります。
- ディスコードサーバーで【自己紹介、ロール付与、参加加入申請】後、サーバーにご参加ください。
